# Digital Suggestion Box

A secure and anonymous college feedback system built using PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.

## Features

- Student and Admin separate access
- College code verification for students
- Completely anonymous student suggestions
- Suggestion categories
- Unique Suggestion ID generation
- Suggestion status tracking
- Admin registration and login
- Secure password hashing
- Forgot password and secure reset token
- Admin dashboard
- Search and filter suggestions
- Admin status updates
- Admin responses
- Responsive modern UI

## Technology Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP
- Database Management: phpMyAdmin
